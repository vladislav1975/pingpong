# 🏓 Игра Пинг-Понг (PyQt5)

Простая настольная игра на Python с графическим интерфейсом PyQt5. Игра включает звук, счёт, жизни, изображение на фоне и кнопку перезапуска. Отличный проект для изучения GUI-разработки!

## 🎮 Возможности

- Увеличение скорости мяча после каждого удара
- Отображение очков, жизней и текущей скорости
- Экран «Игра окончена» и кнопка «Сыграть снова»
- Звуковой эффект при ударе мяча о ракетку
- Фоновое изображение справа в окне
- Чистый и отзывчивый интерфейс PyQt5


## 🛠 Требования

- Python 3.8+
- PyQt5
- PyQt5.QtMultimedia (для звука)
- `background.jpg` — изображение для фона
- `kick.wav` — звуковой файл удара
